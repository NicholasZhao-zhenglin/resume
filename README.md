# 简历与历史版本

[下载最新版 Word 简历](latest/resume.docx) · [阅读纯文本](latest/resume.txt) · [查看所有历史版本](history/)

每次修改完成后更新 `latest/`，并在 `history/版本号/` 保留独立快照。Git 提交记录用于追踪同步变化；旧快照不覆盖、不删除。

`version.json` 保存版本号、父版本、时间及 SHA-256，便于核对文件。首次版本为原始简历备份，后续修改以最近完成版本为基础。

每份简历另有可读文件名：`姓名_目标岗位_YYYYMMDD-HHMMSS_更新重点_版本号.docx`。时间为北京时间，重点如“新增专利项目”或“强化RAG检索经历”，由实际修改决定。打开 latest 或 history 可直接按名称区分；`resume.docx` 固定链接继续可用。
